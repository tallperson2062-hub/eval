```text

```



The test passes.

Your system would say:

```text

```

But the function is actually wrong.

### So I recommend changing:

```text
Accuracy
```

to:

```text
Test Pass Rate
```

This is much more honest and technically correct.

This tells you:

# One very important problem in your project

Your AI debugger currently has the ability to modify **tests as well as code**.

That can cause a problem.

Imagine:

```text
Code is wrong
        ↓
Test fails
        ↓
AI changes the test
        ↓
Test passes
```

Your evaluation might say:

```text
SUCCESS ✅
```

even though the original problem wasn't really fixed.

### Better approach

Keep the original/acceptance tests **unchanged**.

Let the AI modify:

```text
source code ✅
```

but don't let it modify:

```text
independent acceptance tests ❌
```

Then run those original tests after the AI finishes.

That gives you a much more trustworthy evaluation.
